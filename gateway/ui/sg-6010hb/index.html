① 开环 30 rpm / 1.5 V / 6 A / 5 s，检查原始编码器连续运动；起动不足先停机分析，再短测 3 V。② 停机检查 raw 抖动与错误，再做约 50 s 开环校准。③ 电压 → 电流 → 力矩 → 速度 → 位置 → MIT，逐阶段批准。
