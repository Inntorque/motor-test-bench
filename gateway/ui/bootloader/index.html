设备

不连接

连接 J-Link 的 SWDIO、SWCLK、GND 和 VTref；目标板自行供电。先结束其他 APP 的测试并停止输出。

选择“连接”并授权探针后，持续自动识别和重连；选择“不连接”停止。

尚未读取芯片信息

使用 Chrome / Edge。USB 权限不足时需处理系统探针权限；Windows 需要 WebUSB 可访问的驱动。CAN 适配器不能用于首次 SWD 烧录。

备份与烧录

正在加载

备份烧录：先保存 512 KiB 全片备份，再更新镜像涉及的 Boot 页面并全片校验。直接烧录：不备份，擦除全部 32 KiB Boot 分区，写入镜像并校验该分区；两种方式均在校验通过后复位。

直接烧录会清除 Boot 分区原有内容，不创建恢复备份；两种方式均不擦写 Boot 分区以外的应用和参数。

总进度 0% · 100% 表示本次操作全部完成。

烧录期间保持本页打开及 USB / 电源连接。Bootloader 不替代电机应用；旧固件若从 0x08000000 启动，烧录后仍需 OTA 匹配本布局的电机应用。
