# 驱动板接入验收

记录设备 UID、硬件/固件版本、协议版本、上位机版本、系统与适配器。

- 仅插入 USB-CAN、驱动板未上电时不显示驱动已连接；上电回传后身份与状态一致。
- 主版本不兼容只读；能力缺失时对应模式不可启动。
- 电流最小/最大边界及越界值分别验证，负电流方向与约定一致。
- ACCEPTED/PENDING 不显示执行完成；最终 CONFIRMED 和新鲜运行回读缺一不可。
- 正常启动、目标设置、停止，核对命令序号和实际回读；STOP 可重复且不会重启输出。
- 延迟旧 START、断开/重连、设备重启、会话过期不能造成旧命令重新生效。
- 断开控制心跳后验证板端在声明的看门狗时间内撤销输出。
- STATUS、采样、诊断分别停更，验证必要反馈过期会停止、可选诊断不被误判为全设备失联。
- 采样丢包、乱序、重复、时间回绕及无效字段不产生伪造特性点。
- 比对 Iq 峰值/母线电流、转速轴端、位置微转和温度量纲。
- 加载中实测轴端扭矩与目标分别保存；零速 5 秒确认后只记录一个实际堵转终点。
- Windows 与 Ubuntu 使用同样配置与设备执行上述项目，保留原始记录和差异说明。

只有完成实际硬件验收，才能将设备列入“已验证驱动板”。虚拟板或仅协议编码测试通过不能替代本清单。
