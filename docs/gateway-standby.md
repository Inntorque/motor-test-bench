# 总网关宇宙待机

2026-11-03。总网关右上角增加“待机模式”，点击进入全网页粒子场，点击“返回总网关”或按 Esc 退出。入口只在总网关，四个 APP 的页面、功能和入口版本保持原样；不自动进入待机，不触及设备通信和控制。

## 视觉

参考 [omp.sh](https://omp.sh/) 的黑底细噪点、方形粒子、品红/青蓝流动边界、散射白色颗粒和克制的等宽排字，扩展为星云旋臂、环状暗核及远近星尘。粒子沿不同半径以不同速度流动，指针带来轻微视差；LOGO、返回按钮和说明保持固定。星云与颗粒由 TypeScript / WebGL2 着色器绘制，不加载第三方图片、字体、分析脚本或渲染库。

## 生命周期与资源

- 首页只加载入口代码，点击后才下载带内容哈希的粒子模块、创建 GPU 上下文和分配粒子缓冲。
- 一次待机使用一个 WebGL2 上下文，两个绘制阶段处理细噪点背景与粒子。粒子数量随窗口面积变化，上限 110000；渲染尺寸上限 1920×1080，像素比例上限 1.25，绘制上限 30 Hz。
- 待机期间暂停总网关原头像的动画。浏览器隐藏时停止待机绘制，恢复可见后继续；系统要求减少动态效果时保留静态粒子画面。
- 退出后取消动画帧、移除监听器、删除 GPU 对象并释放待机上下文，恢复原头像行为及入口焦点。快速关闭、重复进入和模块尚未下载完成便退出均单独校验。
- 使用原生模态对话框处理键盘焦点和 Esc。WebGL 无法创建时显示提示，返回按钮仍可用。

## 维护

| 文件 | 职责 |
| --- | --- |
| `gateway/index.html`、`gateway/styles.css` | 入口、待机框架与响应式排布 |
| `gateway/standby/entry.ts` | 打开/关闭、焦点、延迟加载与清理 |
| `gateway/standby/universe.ts` | 粒子着色器、视差、绘制节奏与 GPU 生命周期 |
| `gateway/icon-motion.ts` | 待机期间暂停原头像，退出恢复 |
| `scripts/build_gateway.py` | 把首页拆分模块一并复制到 Pages 内容，保留哈希引用 |

```sh
npm run build
python3 scripts/build_gateway.py
node tests/gateway-standby-ui.mjs

```
