# 西格电机电流环接入

工作台仅通过 `motor_current.py` 接入 `/home/dash/Desktop/xige_foc/xige_foc` 的现有本机 CAN 服务 `127.0.0.1:8892`。CAN 适配器由该服务独占，工作台不复制电机固件或整套原上位机功能。

## 已接入协议

- CAN 参数主机 ID `0x610 + node`，设备 ID `0x590 + node`；本机实测节点 0、500 kbit/s。
- `0x12 CTRL_SET`：字段 1、32 位小端有符号 mA，指定 Iq 目标；需 ACK。
- `0x08 MOTOR_CTRL`：启动固定为模式 5；STOP 为 enable=0。启动和停止由原服务请求新鲜状态确认。
- `0xA5` 控制状态、`0xA6` Id/Iq 反馈、运行状态、编码器有效性与温度保护用于监督。
- `0xA5` 的 Iq 是固件内部斜坡参考，不能与新写入目标立即相等作为验收。工作台分别显示已 ACK 的目标和实际 Iq/Id。
- 只读 ID7 电流上限、ID0/1/2 电角校准参数，验证指定工程与实际固件应答后显示已连接。

## 步进规则

输入步长 0.001–5 A（1 mA 分辨率）、步进间隔 0.2–10 s、持续时间 1–255 s。输入默认留空，由操作者填写并启动。步进间隔表示两次电流目标增加之间的秒数，例如 2 s 表示每隔 2 秒增加一次。

启动先将 Iq 设为 0，再启用电流模式；第一个周期结束后增加一次步长。任务在通信桥后端执行，不能重入，不追赶积压的步进命令。通信耗时超过一个步进周期则停机，需增大间隔。

目标不超过 ID7 读回限值，旧 0x0A00–0x0A10 固件再限制为 1 A。达到上限后保持至保护或持续时间到期，不修改保护参数、不自动扩大限值，也不将“达到上限”报告为“已触发保护”。

保护、电流/编码器/温度反馈异常、通信失败、页面心跳超过 2 s、手动 STOP 或持续时间到期都会结束任务。固件同时收到有限时长的启动参数，并保留原 CAN 心跳/页面看门狗。结束发送 STOP，确认新鲜 IDLE/输出关闭，再将 Iq 目标归零。关闭未确认时明确显示，阻止再次启动。任务保存结束原因、末次目标和软件采集的 Iq 幅值峰值；该峰值不是固件每拍的保护峰值。

未接入速度/位置/MIT、校准、OTA、参数保存或保护阈值设置。

2026-10-15 实机只读接入：`/dev/ttyACM0`，固件 `0x0A1C`，节点 0，设备电流上限 5 A，电角校准与 Id/Iq 有效，IDLE/输出关闭。代理未发送启动或非零电流目标；实际步进及保护性能留给操作者现场验证。离线假设备覆盖限值钳位、持续时间、保护、写入失败、页面心跳丢失和手动取消。

## 电机温度显示

工作台显示参考工程 CAN 0xA2 的 NTC 温度 `snapshot.ntc.temp_c`（°C，1 位小数），随电机状态轮询更新。仅当电机已连接、NTC valid、无 fault 且 age_s 不超过 1.5 秒时显示；否则为空并注明未连接、故障或过期。过温及过温锁存明确提示，不发送任何温度配置命令。

空闲时目标 Iq 使用新鲜的设备控制状态回读，不用工作台初始 0 A 代替设备值。电流环卡片同时显示编码器输出角度和转速，沿用参考工程的转子反馈及电机档案减速比换算，不清零编码器、不写入控制目标。已连接电机的空闲读取发生瞬时失败后，至少等待 1 秒再只读恢复；失败期间保持未连接、隐藏旧值。首次连接及主动断开后不自动建立连接，运行中仍按原规则故障停机。
