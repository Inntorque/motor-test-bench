# 电机电流与最大输出接口

工作台通过 `motor_current.py` 访问本机 CAN 服务 `127.0.0.1:8892`，适配器由该服务独占。默认可使用仓库内 `vendor/xige_foc` 主机模块，也可通过 `MOTORBENCH_XIGE_ROOT` 或 `workbench.local.json` 指向独立工程。路径发现顺序见 [启动说明](../README.md#ubuntu--windows-一键启动与关闭)。

## 模式与版本

| 模式 | 固件模式 | 行为 |
|---|---|---|
| 独立电流步进 | MODE 5 | 按步长、间隔和持续时间逐级发送目标，达到本次限值后保持 |
| `full_current` | MODE 5 | 一次下发固定 10 A 对照目标，固件使用已有斜坡，无固定结束时长 |
| `maximum_output` | MODE 7 | MCU 根据当前约束动态分配 Iq；需要 0x0A3C 或更新固件 |

最大输出不是始终保持某个固定安培值。配套固件受电流矢量、ADC 可测范围、电压和估算供电能力约束；负载改变时继续重算参考。Id 弱磁下限可配置，默认 0（关闭），允许的负 Id 值需有电机资料或实测依据。

## 协议与反馈

- CAN 参数主机 ID `0x610 + node`，设备 ID `0x590 + node`；节点与波特率由配置指定。
- `0x12 CTRL_SET` 字段 1 使用 32 位小端有符号 mA，指定 Iq 目标；需要 ACK。
- `0x08 MOTOR_CTRL` 选择启动模式；`enable=0` 停止。启动与停止均需新鲜设备状态确认。
- `0xA5` 报告内部斜坡参考，`0xA6` 报告实际 Id/Iq；目标 ACK 与实际跟踪结果分别记录。
- ID0/1/2 用于验证电角校准，ID7 用于读取相电流保护限值；NTC、编码器、运行状态和故障原因参与监督。
- 最大输出设置字段 13/14/15/16/17 分别为母线 mA、负 Id 下限 mA、相电流运行上限 mA、母线 mV、可选转速软限幅 rpm。相电流运行上限 0 表示按现有边界推导，Id 与转速软限幅 0 表示关闭。

`full_current` 和 `maximum_output` 沿用已有运行期 ID7 设置并重新读回确认的流程，不保存至 Flash。支持上限根据实际固件版本判断，不能把跳闸阈值直接等同于可持续目标电流。独立步进不会自动提高设备保护限值。

## 独立步进

步长 0.001–5 A，分辨率 1 mA；间隔 0.2–10 s，持续时间 1–255 s。启动先将目标归零、确认电流模式，再按周期增加目标。不追赶积压命令，目标不得超过读回限值；通信耗时超过步进周期时结束该步进任务。

## 诊断与记录

`GET /api/max-output/status?cached=1` 只读取后台缓存，不等待 CAN 诊断事务。独立只读线程按低优先级读取最大输出诊断；原有控制与停止请求优先。详情见 [两阶段测试说明](coupled-current.md#诊断与完整性)。

电机已连接且 NTC 有效、新鲜、无故障时显示温度，否则留空并提示原因。位置、速度沿用固件反馈和电机档案减速比，不清零编码器。转速对照页另有明确标注的 9.78 换算比，不修改控制器参数。

## 停止与恢复

已有保护、电流/编码器/温度反馈异常、通信失效、控制心跳丢失或手动停止均走原停止路径。停止后确认新鲜 IDLE/输出关闭，再将目标归零；未确认关闭时明确显示并阻止再次启动。直接结束进程不等于关闭硬件输出。

独立接口不会保存控制参数、执行校准或刷写固件。工作台主机模块不包含 MCU 镜像；最大输出模式的硬件验收、允许的负 Id、绝对电流增益和编码器角度精度需在配套固件工程及现场完成。
