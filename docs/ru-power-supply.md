# 万瑞达 RU-36-6060 电机电源

协议依据为设备随附的《RU 系列通信协议》第 1–3 页和《万瑞达 RU 系列直流电源使用手册》第 3、6、7、9 页。设备手册由现场保管，接线、面板通信方式和额定值须与实物核对。

## 使用

1. 电机电源默认使用万瑞达 RU-36-6060 / RU 系列 Modbus RTU。旧浏览器 SSJ 配置首次加载时迁移到 RU，之后记住手动选择的协议；制动电源仍为 SSJ。选择实际串口，RU 默认 **9600 bps、8N1、地址 1**；面板不同则按实物填写。支持 RS485/RS232 串口适配器。RJ45 上的 RS485 接线口不能直接视作 Ethernet；TCP 选项只用于已配置为 RTU 透明传输的网关，不表示原生 Modbus TCP。
2. 连接仅只读握手，核对真实 CRC 应答，自动读取电压/电流小数位及额定值。额定值不按型号名称猜测，不使用旧 SSJ 的额定值作为新 RU 的依据。连接不打开输出，不改 ID、波特率、存储或保护。
3. 电机电源操作区只保留开关，使用面板已有的 **24 V、20 A 限流**预设。实际供电电流由负载决定，电机 Iq 在电机控制区设置。设备当前设定另行只读显示，连接和加载页面不改写这些值。
4. 点击开启电机电源时，只读核对已有预设为 24 V / 20 A，再打开输出并确认真实状态；预设不匹配则拒绝，软件不代为设置。若超过电源额定范围或寄存器范围也拒绝。制动电源默认恒流 CC 控制，电压上限 24 V，仅开放 0–2.3 A 目标电流输入和设置按钮；前后端均拒绝超过 2.3 A 的设置与开启请求。先设置电流并核对读回，才能开启。修改输入后，旧设定不匹配时禁用开启；后端也会重新读取并检查。
5. OFF 直接关闭输出并读回确认；断开通信不会代替 OFF。断线、错误 CRC 或错误写入回显不会显示连接/操作成功。

## 协议映射

| 数据 | 功能码 | 十进制地址 |
|---|---|---|
| 实际电压/电流 | 04 | 100–101 |
| 额定电压/电流 | 04 | 103–104 |
| 电压/电流小数位 | 04 | 106–107 |
| CC/CV | 02 | 116–117 |
| OVP/OCP/OTP 状态 | 02 | 120–122 |
| 输出开关 | 01 / 05 | 133，ON=FF00、OFF=0000 |
| OVP/OCP 使能 | 01，只读 | 136–137 |
| V/A 设定 | 03 / 16 | 149–150，同帧写入并回读 |
| OVP/OCP 保护值 | 03，只读 | 157–158 |

物理 V/A = 原始寄存器 / 10ⁿ，小数位 n 从设备读取。仅读手册列出的连续有效地址，不跨读未列出的工厂地址。不发送广播、存储、开机输出或负电流/定制换相操作；保护触发时阻止 ON，不自动解除保护或重试。

RU 无功率寄存器，本机使用真实 V×A 计算功率，页面标注计算来源。桥内统一 `status & 0x80` 为输出 ON，这是兼容工作台的映射，不是 RU 原始状态寄存器；CC/CV 和保护位单独保存。原 `settings[1:3]` V/A 接口保持兼容，现有记录、曲线、自动测试继续使用真实读数。

## 限幅边界

- 最大限幅约束工作台发出的 V/A 设定，包括直接调用设置或 ON API；前端同时禁用超限操作。按实际电源精度取整后再次检查，0 限幅阻止正值目标。
- 这是工作台设定范围控制；设备 OVP/OCP 属于独立跳闸保护，页面读回数值、使能和故障状态，保留原设置。本次不将最大限幅写成 OVP/OCP，也不保证约束面板或其他外部接口的设置。
- 输出开启时，新限幅低于当前目标或实测值会拒绝应用；先降低设定或关闭输出。输出关闭时可先应用更低限幅，旧目标若超限，将阻止后续设置/开启，需填写新目标。
- 电机电源的软件监测边界仍为 24 V / 20 A，面板工作预设为 24 V / 20 A；连接时设置本机监测配置，不写入设备。电源直流电流与电机 Iq 相电流为不同通道。

制动电源固定保留 SSJ 协议；电机电源也可切回原 SSJ。旧电机电源配置首次迁移到 RU 时使用 RU 默认通信参数，保留串口选择并清除旧设备额定显示，连接时重新读取。

兼容 API：带本机令牌 POST `/api/supplies/motor-supply/limits`，仅接受 `maxVoltage:24`、`maxCurrent:20`，不写设备保护参数。原连接、读取、设置、输出 API 路径保留。

## 验证状态

协议桩检查覆盖只读握手、自动缩放、真实报文/线圈编码、V/A 回读、设备保护阻断、CRC/错误回显、额定/最大限幅、取整越界、输出开启时收紧限幅和 API 令牌；旧 SSJ 回归保留。RS485 串口、设备地址及面板设定由现场选择并核对；自动化测试使用协议替身，不替代具体设备的实物读写与输出验收。

## 制动电源恒流控制

制动侧使用 SSJ。沿用已跑通的 SSJ 协议，以 2001/2002 同帧设置电压上限 24 V 和目标电流（0–2.3 A），没有新增或猜测强制 CC 切换寄存器。恒流时实际电压随负载变化；若达到电压上限仍达不到目标电流，电源会处于 CV，页面提示尚未进入恒流。

实际模式按手册状态寄存器 1007 解码：bit 5 为 CC、bit 6 为 CV、bit 7 为输出开关。输出关闭时显示待开启后确认；断连或模式位不明确时不宣称 CC。依据为 SSJ 设备手册及已验证的 SSJ 控制寄存器映射。该接口不改写设备保护参数。
