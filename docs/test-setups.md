# 电机测试配置与减速比

2026-10-27。电机、驱动板仍在右上角原选择入口管理。每台电机可保存多个机械测试配置，共用同一电机身份；驱动板独立选择。工作台布局、加载/电流控制流程、SDK 和 CAN 协议不变。

## 使用方式

1. 展开“选择电机和驱动板”，选择或新建电机与驱动板。
2. 点击“新建配置”，填写配置名称，选择裸机或带减速箱。
3. 裸机对应电机轴直测，比例固定为 1；带减速箱对应输出轴测量，填写本次实际减速比和减速箱名称。
4. 质量和体积填写本次被测对象：裸机为电机本体，带减速箱为被测总成；未知时留空。
5. 点击“保存配置”，再点击“应用选择”。新配置统一用于工作台折算显示、专项测试和完整参数记录。

已存在的配置可通过“编辑配置”修改。编辑并保存会更新该档案的修订号；新建/选择草稿需点“应用选择”后才作为当前选择。测试、记录或电机输出进行中，配置切换与编辑被锁定，停止后可修改；这只锁定配置操作，不改变原控制算法、运行边界或保护。

## 换算口径

`i = 转子转速 / 被测轴转速`。比例为正数；转向符号保留在原始反馈中。

- 折算角度、转速：转子反馈除以 `i`。
- 专项的被测轴位置、速度目标：乘以 `i`，再按既有协议单位发送。
- 转矩传感器的转矩和转速已经属于实际安装轴端，不重复换算。
- 机械功率使用同一传感器帧的转矩与转速，不受减速比二次缩放。
- 输出端等效 Kt 不直接当作电机本体 Kt；不假设减速箱效率。
- 按减速比推算的角度是折算反馈，不是独立输出编码器实测。

未选择测试配置时，工作台原始数据仍可记录，折算角度/转速留空；新专项需先选择配置。更换电机时不会继承另一台电机的配置。

## 冻结与历史记录

每次测试开始保存所选电机、驱动板及完整 `testSubject.testSetup` 快照，包括配置 ID、修订号、名称、机械形式、轴端、比例、质量、体积和比例来源。专项请求携带配置 ID 与修订号；页面过期时先刷新，不沿用另一版本的换算参数。

专项原始记录与其关联的完整记录使用同一快照。已有手动完整记录只有在测试对象和配置相同时才关联，不因专项结束而关闭。更换后续配置或修改名称不重算旧记录。

CSV/JSONL 附加以下配置列：

- `test_setup_id` / `test_setup_name`
- `gearbox_name` / `has_gearbox`
- `reduction_ratio` / `measurement_axis`
- `measured_object_mass_kg` / `measured_object_volume_L`

原始转子角度、转速与折算值分别保留。旧记录没有配置时显示“测试配置未记录”，不使用当前比例补算。历史文件不迁移、不改写。

## 旧配置

本地 `.runtime/test-subjects.json` 升级为 schema 2。原 `profiles/bench.json` 只作为一次性旧档案来源：原设备下导入“原带减速箱配置（待确认）”，不自动选中，不复制到其他电机。旧 9.67 与旧档案中另记的 9.78 未经本次实测确认；应填写现场确认值后保存。后续计算不再读取固定档案的比例。

选择和保存仅改变上位机的机械测试配置，不修改极对数、编码器分辨率、校准、FOC 参数或驱动板 Flash。更换电机后仍需确保驱动侧电机参数正确。
