# 已实现的专项测试

入口：工作台左侧“专项测试 → 被动测量与统计”。这三项仅测量与记录，不启动/停止电机，不改变电源输出，也不写传感器参数。操作者在原工作台控制运行工况。结束采集按钮只结束记录。另有 [空载和带载自动脚本](automatic-tests.md)，其启动按钮会实际控制电机。

## 项目

- 零加载基线：要求扭矩传感器真实连接；制动电源新鲜状态为 OFF，或由操作者明确勾选现场励磁已关闭/断开的人工确认。已知电源 ON 时人工确认不能绕过。输出有符号扭矩、转速、计算轴功率的均值、最小值、最大值、总体标准差、RMS、峰峰值。
- 稳态波动：要求真实传感器及工况稳定确认；有效阶段如观察到目标 Iq 或制动设置变化，或已接入的电机/制动反馈中断，则保留数据并标为中断。报告转矩/转速峰峰波动率和变异系数。没有有效转动时不能评定运转波动。
- NTC 温度记录：使用现有电机 NTC，按有效的新电机快照记录，不把重复缓存当作 1000 Hz 测量；记录初温、末温、最高温、温度变化。环境温度可手动输入，末次温升为末温减环境温度。只代表现有测点，不自动判定绕组温度、热稳定或额定持续能力。

## 配方与统计

有效采集 1–3600 秒，稳定等待 0–300 秒。等待阶段原始数据保留，但不计入统计。均值绝对值不高于归一化下限时，波动率留空。默认下限转矩 0.01 N·m、转速 1 rpm，可自行调整；这些是统计处理参数，不是产品验收限值。

峰峰波动率 = (最大值−最小值)/|均值|×100%；变异系数 = 标准差/|均值|×100%。未配置产品合格阈值，因此输出描述性统计和数据有效性，不自动判定产品通过。

## 数据和限制

- 每次记录保存在 `recordings/specialized/<id>/data.csv` 与 `report.json`，独立于旧试验记录。
- HEX 每个 CRC 有效帧逐帧写 CSV，后台约每 20 ms 取增量数据，定期刷新文件；RTU 记录每次新的实际读取结果。NTC 与电流统计按独立的新电机快照计数。
- CSV 包含采样类型、PC 接收时刻、帧序号、是否进入统计、原始缩放后的扭矩/转速/功率、目标/实际 Iq、Id 及电机快照时刻、温度。
- 时间为 PC 接收时间，USB 同批数据可以同时间戳；1000 帧/秒不表示有效测量带宽。当前不用于快速阶跃、精确时延或频带验收。
- 曲线预览约 0.5 秒抽点，最多 300 点/指标并压缩历史，完整数据不按预览抽样；统计使用全部有效原始点。
- 断线、超时、帧序号重置/丢失、传感器配置变化会使记录中断。手动提前结束为部分记录。服务重启后，未完成记录标为中断。
- 切换到专项页面仍保持现有页面会话的电机反馈轮询；关闭页面后原电机看门狗仍有效，NTC 源失效会中断温度记录。
- 控制器保护、机械行程和原步进持续时间不变。长时采集不会延长原电机输出任务，不保证整段记录处于恒定负载。

## API

- GET `/api/specialized/status`：当前任务、历史、接口可用性。
- POST `/api/specialized/start`：带原本机令牌提交配方。
- POST `/api/specialized/stop`：带令牌及任务 id 结束采集。
- GET `/api/specialized/files/<id>/data.csv` 或 `report.json`：导出。

本页被动测量不控制位置/速度；自动脚本单独接入参考工程已有位置/速度控制与带载最大转矩记录。独立绝对定位验收、背隙/刚度、自动制动加载和精确瞬态带宽验收仍未接入。
