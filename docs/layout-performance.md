# 页面留白与运行资源优化

2026-10-27。保留现有功能、按钮、说明、图表样式和数据计算口径。仅将编码器对比接到左侧记录区之后，操作事件随后，消除原两栏高度差造成的留白。未改控制算法、设备采样、保护、SDK或CAN协议。

## 实现范围

- 网页传感器缓存仍为最近16000帧，改用固定容量环形缓存，按序号读取新增帧；复位和缺口标记保留。实时页面直接读取已有SSE缓存，避免经JSON响应再次编码、解析。
- 编码器仍按100ms采样显示、保留12000点和原分箱定义。仅重算有新增/过期点的分箱，每个分箱仍按原时间顺序求和，以保持轴范围和SVG路径。
- 可见图表正常刷新，不可见/后台图表保留上次绘制结果；采样与缓存继续，返回视口立即使用最新数据。没有数据待绘制时不持续请求动画帧。主图显示上限仍为30Hz。
- 图表只接收相关传感器/电机对象，SVG绘制单独记忆化；电源状态更新不再无条件触发编码器整图更新。
- 测试对象档案缓存已解析内容，通过文件标识、大小和纳秒修改时间失效。修改采用独立副本，原子保存成功后才发布缓存；外部替换文件仍可刷新。
- SSE读取只深拷贝要发给网页的事件；跳过的内部事件保留ID和类型以推进游标。完整采集和记录订阅者仍接收原始完整事件。
- 统一缓存状态与直读健康接口的服务标识，避免网页将已运行的服务误报为“通信桥未启动”。

| 路径 | 优化前 | 优化后 | 函数耗时减少 |

| 编码器分箱与路径 | 724.38 ms | 99.96 ms | 86.2% |

## 浏览器回放

全部API被拦截，以合成数据进行名义1000帧/秒回放，不访问硬件。3组对照各记录3秒前台运行，取中位数。

- 相同1366px窗口，记录区到编码器卡片间距：268.30px → 18px。
- 1.2秒无数据空闲期间的requestAnimationFrame请求：72 → 0。
- 三秒接收帧数：3000 → 3000；显示频率均约30Hz。
- JS堆占用快照中位数：11.60MB → 9.29MB。这不是整个浏览器进程的内存。
- 三秒渲染进程任务耗时：0.706s → 0.715s；脚本耗时：0.351s → 0.356s。前台整体耗时未见明显下降，不宣称整页CPU降低。
