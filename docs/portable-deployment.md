# Inntorque Windows / Ubuntu 便携上位机

解压完整 portable 包到普通用户可写的固定目录。Windows 双击根目录“测功机.exe”；Ubuntu 首次执行“首次配置Ubuntu.sh”，之后双击“测功机”或使用应用菜单快捷方式。不要直接启动 versions 内的主程序；根目录启动器负责版本切换与恢复。Ubuntu 需有 Electron 所需桌面运行库，串口和 USB 权限依适配器配置；首次脚本只为当前软件路径配置 AppArmor userns 权限，不关闭系统沙箱或自动开启设备输出。

运行无需 Git、Node.js、Python 或 Go。首版目标 Windows x64 与 Ubuntu x64；实际系统/驱动验收记录见验证报告。离线可以正常测功，在线用于检查与下载更新。

## 文件与数据

- 测功机.exe / 测功机：固定启动器。
- versions/<版本>/：各版本程序和依赖；旧版保留供启动失败回退。
- active.json：当前版本指针，由启动器管理。
- config/：本地设备配置、窗口状态和 IndexedDB。
- 测功数据/：CSV/JSONL、测量表、特性点和报告，更新不会覆盖。
- updates/：签名清单、下载暂存及更新前配置快照。
- logs/：启动和更新诊断。

同一目录只运行一个实例。移动整个目录前先退出。既有旧桌面版使用系统配置目录；迁移到便携版前，应在旧版退出后复制配置和数据：旧 Ubuntu 版 `~/.config/InntorqueBench/` 的内容放入 `config/`，旧软件目录 `测功数据/` 的内容放入新根目录同名文件夹（先备份，遇同名记录不覆盖），不能把正在写入的数据库直接覆盖到新版。

## 检查与执行更新

启动 10 秒后以及运行中每 10 分钟检查 GitHub Releases；帮助菜单可手动检查。发现新版显示版本和说明。正在试验时不弹出自动更新对话框；菜单保留新版提示。软件关闭时不驻留检查，下一次启动再检查。

下载完成先验证 Ed25519 清单签名、平台、架构、协议和数据格式兼容性，再验证包长度及 SHA-256。普通代码提交不会直接改变现场程序。点击“保存并重启更新”后，先结束试验、关闭设备输出；更新准备会锁定新的控制命令，正常退出功能不受这项更新检查影响。保存失败保持当前窗口，不安排更新。

旧进程退出后解压到新版本目录，备份 config，再切换 active.json。新版需在 45 秒内确认界面已渲染且通信 Worker 健康接口已响应；否则自动恢复旧版和更新前配置。停电/进程退出导致启动确认未完成时，下次启动按事务状态恢复。原始测功数据一直独立保留。启动检查只证明应用初始化成功，不证明真实设备连接成功。

更换更新信任公钥或升级不兼容的启动器版本，需要重新部署经核验的便携包，并保留 config 和测功数据；应用不会跳过 minLauncher 检查强行升级。当前发布器只生成启动器 v1 兼容包。

## 网络与发布权限

更新源为 Inntorque/motor-test-bench 的正式 Releases，下载需要测试电脑可访问 GitHub。当前客户端支持公开发布附件；私有附件的认证分发尚未配置，不内置开发者令牌。2026-11-17 已只读确认现有仓库为 PUBLIC；更改可见性前必须重新验证下载权限。

发行清单签名与 Windows Authenticode 是两件事：前者已实现；Windows 可信代码签名证书尚需部署方提供，未签署的测试 EXE 可能触发 SmartScreen。不把本地功能验证称作已完成 Windows 现场验收。
