# 测功机 1.2.0

先启动电机，观察空载转速。确认目标输出与转速稳定后点击“② 开启力矩输出”，此刻为加载试验零点。每 2 秒提高一级制动目标，曲线持续记录轴端扭矩和转速，包含负载上升时的降速过程。表中同时保留加载目标、过程读数和级末汇总。手动停止保留已采段，带电连续零速 5 秒且编码器确认后标记堵转。

默认以实测扭矩为横轴绘制 U、Po、n、I、Pi 和效率，每次有有效加载点的试验结束后，桌面版自动把独立 SVG 写入“测功数据”的本次采集文件夹，也可从图表手动导出。母线读数缺失时对应曲线留空。当前台架的制动标定范围最高为 2.7 N·m。

Windows 与 Ubuntu 共用采集和绘图核心。便携启动器支持签名更新、断网安装已下载的更新和启动失败回退。MBP/1.0 驱动 SDK 1.1.0 提供 C11 设备协议栈、板级接口、C99 编解码和虚拟示例。
