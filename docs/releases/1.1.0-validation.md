## 审查中修正

- 标准驱动的 PENDING/ACCEPTED/APPLIED 不再被当作最终命令确认；模式、反馈、电流边界、电流定义和看门狗能力不足时不可启动对应模式。
- 更新只在输出关闭且记录保存后安排；普通退出继续沿用现有保存规则。下载或签名失败不改变当前程序；第二个启动器不会在版本切换期间并发打开另一个进程。
- 新版确认要求 React 界面提交并得到通信健康响应；无确认的正常退出也算启动失败，触发恢复。
- 配置回退有事务标记，可在移动目录后中断再恢复；新版本与原始记录目录分开。
- 更新网络使用 Electron 系统代理处理；窗口在下载中退出时不再调用已销毁的窗口对象。
- 去除了为旧测试模拟字段添加的兼容回退和重复写死的 5014 电流范围；按本轮基线执行 deslop，未整理无关历史代码。
