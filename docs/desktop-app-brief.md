# 网页版上位机交互初稿

日期：2026-10-09。产品设计建议，尚未定稿或实现。硬件依据见[设备与通信笔记](device-and-protocol.md)。用户已选择网页版、GitHub 部署方向；首要测试场景待确定。文档保留原文件路径以维持已有链接。

场景更新：用户补充电机+减速箱+CAN 驱动板与磁粉/离合加载装置，传感器和磁粉装置均有 50/100 N·m 两种规格。完整设备关系、CAN 接入分支和界面扩展见[试验台设备与接入方案](test-bench.md)。下文测量流程保留为基础模块，CAN 控制和加载控制以实际协议确认后扩展。

接入方向更新：用户已确认 LC_CANABLE_V2.1，可根据方案修改固件；采用 USB CDC/SLCAN + Web Serial，首轮能力见 [CAN 接口约定 v1](can-interface-contract.md)。制动器由电源直接驱动，通过控制电流加载，电源可采用网口转 RS485 接入。首页连接区使用“电机”“扭矩传感器”“制动电源”三个角色，各自显示连接和反馈状态；驱动板、电源及网络网关协议仍待确认。

目标体验：**接好 → 看懂读数 → 开始记录 → 停止并导出**。常用操作留在同一工作界面，串口细节与设备高级参数按需展开。

## 网页交付方案

GitHub Pages 提供静态 HTML/CSS/JavaScript 托管并支持 HTTPS，适合本项目的浏览器界面。CAN 适配器与独立的传感器 USB-RS485 经 Web Serial 接入；制动电源经网口转 RS485 接入，根据网关能力使用 HTTP/WebSocket 或本机、台架侧桥接服务，详见[网络接入条件](test-bench.md#网口转-rs485-的网页接入条件)。GitHub Pages 不运行硬件接入后端。[GitHub Pages 说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)、[HTTPS 支持](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https)。

运行链路：GitHub Pages 将网页加载到用户电脑 → 网页通过 Web Serial 访问该电脑的 USB-RS485 → EVG-D200。Modbus 编解码、曲线及记录在浏览器本地完成，方案不上传测量数据。该结构不提供跨互联网远程访问另一台电脑串口的能力。

首版以电脑端 Chrome/Edge 为测试目标，同时用 `navigator.serial` 做能力检测，不只判断浏览器名称。Web Serial 需要安全上下文，首次授权需用户点击触发浏览器端口选择器；`getPorts()` 只能取得已授权端口。[Chrome Web Serial 文档](https://developer.chrome.com/docs/capabilities/serial)、[MDN Web Serial](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API)、[浏览器兼容数据](https://github.com/mdn/browser-compat-data/blob/main/api/Serial.json)。

RS485 直连路线无需安装专用上位机程序；USB-RS485 仍须被操作系统正确识别，是否需要转接器驱动和串口访问权限取决于实际环境。整套台架是否需要桥接服务，取决于电源网关协议及 CAN 实机兼容性。试验时保持页面开启和电脑唤醒；不承诺关闭页面、电脑休眠后继续采集。高速及长时记录须实测，不从网页方案的可行性推导 1000 Hz 无丢样保证。

发布时仅部署构建后的网页资源，手册、工程笔记和试验记录不作为站点资源自动发布。是否公开源码仓库另行确定。

## 主界面

| 区域 | 内容与行为 |
| --- | --- |
| 顶部连接区 | 连接状态、设备/端口、连接或断开按钮；详情中再显示协议、波特率、地址 |
| 主读数 | 扭矩大数字，始终显示 N·m 和正负号；转速为次要读数；缺失数据用“—” |
| 实时曲线 | 默认扭矩；可切换转速，功率确认量纲后再加入；有时间范围、暂停查看、恢复实时 |
| 操作区 | 开始/停止记录为主按钮；传感器清零为次按钮；设置独立入口 |
| 加载区 | 设定电流（A）、输出开关；并列显示实际电流（若支持读回）和实测扭矩，电压与电源状态按需展开 |
| 记录反馈 | 已记录时长、数据量、本地保存状态；结束后提供 CSV 下载 |
| 状态反馈 | 区分串口已打开、收到有效数据、正在记录；按需展开诊断信息 |

曲线暂停仅冻结视图，不停止采集和记录。实时绘图可降低绘制点数，但记录保留全部有效接收数据；避免绘图阻塞接收。屏幕刷新速度不冒充采样率。

## 连接流程

1. 首次进入显示简短接线提示：独立 24 V 供电、黄线 A、蓝线 B、USB-RS485 端口。
2. 用户点击“连接传感器”，在浏览器授权选择器中选定 USB-RS485；已有授权时可列出已授权端口，记住上次成功配置。
3. 默认尝试 Modbus RTU、19200、地址 1；停止位按手册冲突做有限只读探测。
4. 收到连续有效帧、验证结构和 CRC 后显示“正在接收数据”。若小数缩放尚未确认，要明确显示该状态。
5. 无响应时提供具体下一步：检查供电/端口/A-B/传感器当前模式；高级通信配置再按需展开。

不默认遍历并操作电脑上的所有串口，不把任意串口设备识别成 EVG-D200，不因无响应而写入通信设置。手册没有唯一设备身份寄存器，连接文案不能声称自动认证了硬件型号。

## 首版建议范围

测量模块以单个已选传感器 Modbus RTU 作为联调起点；两种量程配置均需登记，同时运行需求待定。CAN/加载模块按试验台方案补充，若首要场景是毫秒级瞬态，应重新评估高速 HEX 的优先级。

- 连接、断开、保存连接配置及清楚的连接诊断。
- 扭矩/转速读数和实时曲线；功率在量纲验证后加入。
- 传感器清零，清零前说明其会改变设备零点及所有输出。
- 试验记录、停止、CSV 下载和通过文件选择器导入历史记录。
- 断线/数据停更反馈，记录中的缺口与操作事件标记。
- 参数页先显示已读取值；扭矩滤波写入可在读写回验通过后加入。
- 制动电源协议确认后加入电流设定、输出开关及可用反馈；电流上下限与电压上限按实际电源和线圈登记，不由 50/100 N·m 推算。

加载输入采用数值框和小步增减，编辑后的值点击“应用”才发送；实际电流缺失时显示“—”，电流设定不冒充实测扭矩。输出开关区分请求状态与电源确认状态。连接及重连不自动使能输出或恢复旧设定；“停止记录”“关闭制动电源输出”“停止电机”分开操作。自动恒扭矩控制保留为后续能力。

高级标定、恢复出厂、模拟量校准、自动切换通信模式作为后续范围。两套设备同时使用及总线拓扑根据用户配置决定。高速模式应有独立引导，说明需要在设备上改回 Modbus，且该模式下远程清零/参数修改尚无已确认通道。

## 清零、滤波与标定

“传感器清零”改变设备零点，不能包装成只改变曲线显示。执行前简短确认当前无扭矩载荷；软件不能凭读数接近零判断是否确实无载荷。执行成功需命令应答及后续读数反馈，记录中写入清零事件；超时不盲目重发状态不明的操作。

“设备滤波”会改变所有输出的动态响应；“曲线平滑”若实现，只影响本地展示。名称、说明及导出字段必须区分，不能静默覆盖原始数据。

“标定”需要已知实际扭矩，调整测量比例；与清零不同。将来可做带原系数备份、输入校验、写入回读的向导，首版无需放在首页。

## 记录与异常行为

建议按试验保存数据及配置快照：开始时间（含时区）、电脑单调时钟相对时间、电脑接收时间、原始整数、换算值和单位、协议、波特率、小数位、滤波及清零/断线事件。加载模块记录电流设定、实际电流（若支持）、输出开关命令及结果。额定量程只在实际规格已确认后保存；未知时保留未知。

记录应增量持久化到浏览器本地存储，结束后提供易读 CSV 下载，避免只把整场试验放在内存里。存储配额、失败恢复和长时记录需验证；不承诺网页可以静默写入任意文件夹。导出失败保留已有记录并允许重试。直接写入用户选定文件可作为后续独立授权能力。数据有效性和导出完整性优先于华丽动画。

| 情况 | 用户看到的反馈 |
| --- | --- |
| 串口忙/无权限 | “端口无法打开”，显示原因和可执行的处理步骤 |
| 端口打开但无数据 | “等待传感器数据”，引导检查通信模式及接线 |
| CRC 或帧结构错误 | 数据质量异常及计数，不把错误帧转成读数 |
| 断线/超时 | 最后读数标灰，注明最后更新时间；曲线出现缺口，不补零 |
| 重连成功 | 新段继续采集，保留断线事件；不在重连时自动清零或重做标定 |
| 记录/磁盘异常 | 明确显示“记录失败/暂停”及原因，不能继续显示正在正常记录 |

设备没有已确认的采样时间戳或帧序号；导出时间须标注为电脑接收时间，不能宣称精确获得设备采样时刻或物理丢帧率。

## 首版验收重点

- 首次用户能够在不理解寄存器的情况下完成连接与一次记录。
- 读数与实物 OLED、已知输入一致，正负号和小数位正确。
- 拔线后数值明确变旧，记录保留缺口；插回后不静默改配置。
- 曲线暂停不会停止记录，导出的有效数据不因图表降采样而缺失。
- 清零结果可确认，试验记录能追溯清零前后变化。
- 显示实测接收率，区分手册标称上传率和传感器实际更新率。
- 电流设定与实测扭矩清楚分开；电源写入失败、未确认或断线时不显示已执行，重连不自动加载。
