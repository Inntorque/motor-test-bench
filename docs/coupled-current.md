# 最大输出与两阶段力矩加载

首页默认 `maximum_output`（MODE 7），可切换 `full_current`（MODE 5，固定 10 A 对照）。新模式需要 0x0A3C 或更新固件。网页检查 `capabilities.maximumOutput` 与固件版本，旧服务不会把新请求误当固定电流流程。

## 设备准备

1. 分别连接电机电源、制动电源、扭矩传感器和 CAN 驱动板，核对真实反馈、串口归属及通信参数。
2. 电机电源使用面板已有的 **24 V / 20 A** 预设，工作台只核对、不改写。直流限流与 Iq 相电流不相等。制动电源保持关闭，电机回到 IDLE。
3. 选择最大输出或固定 10 A 对照。最大输出的相电流运行上限 0 表示自动推导；弱磁 Id 下限默认 0（关闭），填写负值前须确认电机允许范围。

## 两次独立启动

点击 **① 启动最大输出** 后，完成预检、运行期参数读回与 RUN 确认。电流由固件已有 100 A/s 斜坡拉升，制动保持 OFF、0 A。状态变为等待加载后，只有操作者点击 **② 开始力矩加载** 才能开启制动。①的“请求已启用”不表示已达到物理极限。

默认起始力矩 0 N·m、步长 0.1 N·m、每级保持 2 s。零负载级记录零励磁基线，轴承/机械背景扭矩不自动清零。力矩控制使用近 0.5 s 的传感器扭矩幅值均值调整制动电流，电压限压 24 V。

实测首次达到目标减 0.1 N·m 或越过目标后开始保持计时，波动不重置计时；保持完成再加一级。未到达时继续闭环调整，不因等待稳定超时而卸载。慢通信不会追赶执行多次步进。

## 最大输出的含义

配套固件在电流圆与含 Rs 压降的电压椭圆内寻找最大正 Iq，每 10 ms 更新分配，10 kHz 电流环跟踪。参考会随负载、转速和供电余量改变，不能用固定目标 10 A 代替最大可用输出。

- 运行电流取现有 ID7、三相 ADC 正负可测范围及可选运行上限的较小值，并预留跟踪余量；实测 Id 也占用电流圆。运行期 ID7 的设置/读回流程保留，不写入 Flash。
- 电压边界沿用 ID12 与现有 PWM 采样几何限制；24 V 母线不代表可用 dq 相电压矢量也是 24 V。现有配套固件在 PWM 5%–70% 时约为 9 V。
- 母线电流使用 `1.5*(Vd*Id+Vq*Iq)/Vbus` 估算，接近电源设定能力时调节 Iq。电源实测仍单独记录，估算不能代替高速母线电压/电流测量。
- 负 Id 弱磁与可选转速软限幅默认为关闭；已有 R/L、PI、电角标定和保护保持。电压饱和、跟踪波动与诊断质量标记不会新增停机条件。

## 停转与能力边界

扭矩传感器单独报零不会触发卸载。真实停转需同时满足新鲜编码器速度绝对值不大于 0.1 rpm、至少三份不同时间的位置反馈覆盖 1.5 s、位置范围不大于 0.5°，且传感器报零。重复缓存与过期反馈不参与计时。确认过程中冻结制动增量，保留关闭输出前的实测终点，排除 OFF 后的滑行数据。

任一路已有保护、失联、心跳中断或手动停止继续走原停止路径。联动力矩测试沿用 **1.999 A** 制动电流边界和低于 100 N·m 的传感器目标范围。达到制动能力边界且目标未跟随时明确结束原因，不能称为已测得电机极限。

局部电流—扭矩参考覆盖 0.3–2.7 N·m，只作初始估计；低于或超过参考区间依实际反馈调整，不外推标定曲线。轴承背景及原始波动保留，停转读数不能反推制动器完整容量。

## 诊断与完整性

配套固件提供 AS5048A AGC/OCF/COF/磁场标记、magnitude 和独立诊断错误计数；保留 ANGLE 流水线所有权，不用诊断波形伪造角度修正 LUT。ADC 帧包含触发计数/方向、PWM 预装载镜像代数和采样孔径余量；软件镜像不能代替示波器实测。

MCU 持续累计 200 ms 窗口，保存实际 Iq/Id、跟踪 RMS、峰值与饱和比例。网页“窗口证据满足”要求存在分配器限制、无已监测质量标记，且 Iq/Id RMS 误差与平均 Iq 对末端参考之差不超过 `max(0.3 A,5%*max(|Iq_ref|,|Id_ref|))`。该判据只辅助显示，不是计量精度或物理极限认证。

最大输出测试自动创建完整工作台记录；已有手动记录则关联且不自动关闭。记录失败提示异常，不增加电机停机条件。主机模块的运行记录另外包含：

| 文件 | 内容与限制 |
|---|---|
| `maximum_windows.jsonl` | 实际读到的完整统计窗口，含 `previousWindowId` / `unreadWindows` |
| `maximum_trace.csv` | 停机前至多 256 点、2 kHz、128 ms 的冻结轨迹 |
| `maximum_trace_status.json` | 导出完整性、实际行数与错误原因 |

CAN 轮询不能保留每一个窗口，也不能当作全程 10 kHz 原始流。轨迹在停机后低优先级读取，新一轮启动会中断旧导出，不延长电机输出或控制心跳。电流绝对增益、磁编码器周期误差和真实机械扰动的分离仍需独立标定或第二测量基准。

## 接口与图表

`POST /api/coupled-current/start` 接受 `mode: torque_sweep`、`motorMode: maximum_output` 和 `brake: {startNm, stepNm, intervalS, maxNm}`；可选 `negativeIdMinA` / `maxPhaseA`。旧请求不带 `motorMode` 时保留 `full_current`。`POST /api/coupled-current/load` 必须携带当前试验 id，拒绝旧试验或重复加载请求。

六轴特性图按实测扭矩组织转速、电流、效率、功率和温度；轴上限可配置，保留已测轨迹与冻结终点，不补成理想曲线。转速对照页显示传感器与编码器换算值、差值和温度，明确标注换算比，不修改设备控制参数。
